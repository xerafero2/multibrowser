# MultiBrowser

Multi-session browser dengan GeckoView (Firefox engine) dan Flutter UI.

## Fitur
- Halaman utama untuk kelola profil (tambah/edit/hapus)
- Kolom nama profil & User Agent opsional per profil
- Split layar dinamis 1 sampai 4 panel
- Setiap panel punya browser independen
- Penyimpanan profil otomatis (SharedPreferences)

## Build
Push ke branch `main`, buka tab Actions, jalankan workflow **Build APK**, download dari Artifacts.
